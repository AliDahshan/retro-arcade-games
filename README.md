# Retro Game Arcade

A unified classic gaming hub built in Python using the Pyglet library. This arcade features a master main menu launcher that allows players to seamlessly select and play different retro games.

## 🎮 Included Games

1. **Cosmic Shooter (Local Co-Op):** - A fast-paced space arcade shooter supporting 1 or 2 players.
   - Features **6 weapon power-up levels** with massive custom bullet spreads.
   - Includes **scaling Boss Levels every 5 waves** (featuring custom health bars, unique names, and a 3-way bullet attack layout).
   - Defeating a boss triggers a unique death sequence celebration.
   
2. **Snake Xenzia:** - A faithful recreation of the classic Nokia arcade snake game.
   - Grow your snake, avoid crashing into walls or your own tail, and chase down high scores.
